Anything else you want

Add unlimited kinds of search preferences (up to 20 rules per saved search). Nearby services use Google Places API (New) when configured. Listing keyword checks use the listing text. Free-text wishes stay marked needs manual verification rather than being invented.

Examples: swimming pool, 3 km from a supermarket, quiet street, south-facing garden, step-free access.

Save and activate

Your changes are saved as a browser draft first. To update the daily search for all devices, click “Apply to daily search,” then sign in to GitHub and submit the pre-filled issue. Only issues created by the repository owner are accepted; GitHub Actions updates the shared configuration automatically.

← Back to listings

Security: No GitHub personal access token is entered into this website. If Issues are disabled, enable them under GitHub repository Settings → General → Features → Issues. The update workflow must have permission to write repository contents. Changes take effect on the next scheduled search or manual workflow run. Changing requirements cannot make source data more complete.

Daily listing results require compatible provider API subscriptions. Google Places API (New) is separate from Google Routes API and may incur usage charges. For emergency medical access, nearby clinic location is not a guarantee of emergency services or response time.
